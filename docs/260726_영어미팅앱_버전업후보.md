# 버전업 후보 목록

> 1단계 UI 설계(SDD 근접 작업) 중, "더 나은 기능이지만 진입장벽 때문에 낮춘 것"을 기록.
> 8장의 "나중" 항목과 다름 — 8장은 애초에 1단계 범위 밖이었던 기능,
> 이 문서는 1단계 설계 중 발견했지만 의도적으로 단순화한 지점.

---

## 목록

| 항목 | 화면 | 낮춘 이유 | 나중에 추가 시 얻는 것 |
|---|---|---|---|
| 판정 이의제기 재판정(방안 B) | 송신훈련 | 화면 하나 추가, 자가판정만으론 근거 부족 | 사용자가 직접 SRS 값을 보정 가능 |
| 다시 듣기 횟수 제한 | 수신훈련 | 초반 좌절 방지 우선 | 실전 감각(한 번만 듣기) 훈련 |
| 판정 대기 임계값·재시도 정교화 | 수신훈련 로딩 | 세부 수치는 코딩하며 수렴 대상 | 응답성 개선 |
| 성과 화면 추가 지표(총 학습시간·연속일수 등) | 성과 | 통계 과부하로 성과모호 재발 위험 | 동기부여 다각화 |
